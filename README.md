### Fungsi-Fungsi `sp` yang Digunakan di Kalkulator Anda[cite: 1]:

| Perintah di Kode | Kegunaan |
| :--- | :--- |
| `sp.Symbol('x')`[cite: 1] | Memberi tahu Python bahwa huruf `x` adalah variabel matematika.[cite: 1] |
| `sp.sympify(...)`[cite: 1] | Mengubah teks biasa (string) menjadi rumus matematika yang bisa dihitung.[cite: 1] |
| `sp.diff(ekspresi, x)`[cite: 1] | Menghitung turunan (*differentiation*) dari rumus terhadap $x$.[cite: 1] |
| `sp.simplify(...)`[cite: 1] | Menyederhanakan bentuk hasil aljabar.[cite: 1] |
| `sp.sin`, `sp.cos`, `sp.tan`[cite: 1] | Representasi fungsi trigonometri simbolik.[cite: 1] |
